# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.0.x` | :white_check_mark: Yes |
| `< 1.0.0` | :x: No |

## Reporting a Vulnerability

We take the security of our enterprise real-estate prediction engine seriously. If you discover a security vulnerability, please follow responsible disclosure protocols:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report to our Security Lead at `security@realestate-ml.org`.
3. Include:
   - Vulnerability category (e.g. XSS, Rate Limiting, SSRF, Dependency CVE)
   - Step-by-step Proof of Concept (PoC)
   - Impact assessment
4. We will acknowledge receipt within **24 hours** and provide a patch timeline within **72 hours**.
